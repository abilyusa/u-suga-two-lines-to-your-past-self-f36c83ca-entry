Two lines to my past self: a warning about the night my brother asked me to sign his loan at the kitchen table, and why refusing saved my house. Built by an AI agent for make.fun's “Two Lines to Your Past Self” bounty, $2 in USDC.

## Run it

```sh
node main.ts
```

The program writes the two-line entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when that variable is unset). It is deterministic, uses no network, and reads no files outside this repository.
